# 星都异闻录 · 神秘学协会

> 《星都异闻录》外传 · 时间线：2066年12月 – 2067年3月  
> 九委托 + 隐藏委托 · 三层密码入侵 · 白色房间反转 · 四结局

一款**纯前端**的文字解谜推理游戏。你扮演现象调查员**温言**，在神秘学协会的档案室里，靠检索关键词找出线索、把异常归类、逐份归档委托。

零依赖、零构建、零后端 —— 双击 `index.html` 就能玩。

## 🕹️ 玩法说明

1. **入职问卷** —— 第 5 题是三选一，选哪个都行（这是伏笔）。
2. **新人教程** —— 5 页速览委托列表、检索、分类器玩法，可随时跳过。
3. **接单** —— 左侧委托列表依次解锁：完成上一份，才能开启下一份。
4. **读现象描述** —— 委托人描述里藏着检索关键词（人名、日期、物件……）。
5. **信息检索** —— 在右下角检索框输入关键词回车，逐条收集线索。
6. **分类归档** —— 线索集齐后判定现象类别，分类正确才能提交归档。
7. **继续深入** —— 完成 9 份主线委托后，终章自动触发。

💡 卡住了？右下角常驻**判定卡五连问**，逐一对照即可判断分类。

## 🛠 二次创作

游戏内容集中在 `game.js` 的 `CASES` 数组，每份委托是一个纯数据对象：

```js
{
  id: "c01",
  num: "委托 01",
  title: "不会说再见的人",
  type: "遗物",                    // 委托标注的类型（会写进 UI 标题旁）
  client: "陈伯（东里市，72岁）",   // 委托人
  date: "2066-12-03",             // 委托日期（决定案头时钟）
  brief: ["现象描述…"],             // 玩家可见文本，关键词必须出现在这里
  quote: "「……明天见。」",         // 委托人原话引用块
  briefAfter: ["补充说明…"],        // 委托人的补充台词
  clues: [                        // 线索表，key 为可检索关键词
    { key: ["19871016", "1987.10.16"], text: "线索内容…", source: "协会档案 · 东里 1987-01016" },
  ],
  minClues: 4,                    // 集齐多少条才能归档
  classify: CLASSIFY_OPTS,        // 分类器选项
  answer: "obj",                  // 正确分类 id（obj/sight/place/sound/group）
  conclusion: "归档结论…",
}
```

新增委托只需往 `CASES` 里追加一个对象，并加入 `MAIN_IDS`。新增分类则改 `CLASSIFY_OPTS` 与 `JUDGE_CARDS`。

**内容设计约束**（会被 `.test/audit_keywords.js` 自动检查）：每条线索的关键词都必须能在它触发之前被玩家看到 —— 写在现象描述、补充说明或更早的委托里。
